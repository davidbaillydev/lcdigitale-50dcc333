- Kitchen Android app ("LC Cuisine") is a Capacitor shell loading the published /espace URL; native features go through the custom LcKitchen plugin (android/.../LcKitchenPlugin.java) registered with @capacitor/core in src/lib/native-kitchen.ts, retaining window.Capacitor as a fallback and returning null in browsers/SSR; raw TCP printing is restricted to private LAN addresses; APK built by .github/workflows/android-cuisine-apk.yml. Why: Capacitor 7 detects the native plugin without the legacy Plugins object and no third-party print bridge is needed.
