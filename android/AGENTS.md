- Kitchen Android app ("LC Cuisine") is a Capacitor shell loading the published platform site named by server.url in capacitor.config.json, with allowNavigation ["*"] so every redirect stays inside the app instead of failing on an absent browser; android/app/src/main/res/layout/activity_main.xml must stay free of any <WebView> tag because BridgeActivity inflates Capacitor's own layout and an empty one blacks the screen; cleartext and mixed content are allowed for local printers, with backgroundColor matching the brand's dark surface. Native features go through the custom LcKitchen plugin (android/.../LcKitchenPlugin.java) registered with @capacitor/core in src/lib/native-kitchen.ts, retaining window.Capacitor as a fallback and returning null in browsers/SSR; raw TCP printing is restricted to private LAN addresses; APK built by .github/workflows/android-cuisine-apk.yml. Why: Capacitor 7 detects the native plugin without the legacy Plugins object and no third-party print bridge is needed.
